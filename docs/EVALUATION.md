## Evaluation suite

**Simulated APIs, not live results.** Notary's evaluation suite runs the real Notary pipeline (the checker, the Reflector's hypotheses, probes, the Adversary's review, certificates, the Guard and the queue executor) against **simulated** Crustdata and Dodo APIs: an in-process fixture world with the planted quirks listed below. Deterministic model doubles stand in for the models: `fixture.executor-double` (Executor), `fixture.reflector-double` (Reflector), `fixture.adversary-double` (Adversary). These are not live-API results and say nothing about how the real Crustdata or Dodo APIs behave. Real-run results stay in the sections above.

Planted quirks (from the demo code), as scenario `default` applies them:

- `Q1` dodo, GET /payments, GET /refunds: page_size > 100 (documented max) is accepted and silently clamped to 100
- `Q2` dodo, POST /customers/{id}/wallets/ledger-entries: `amount` is read in MAJOR units: crediting 1000 adds 100000 minor units; INTERMITTENT: amounts from 3000 to 3999 are read correctly (minor units)
- `Q3` dodo, POST /customers/{id}/wallets/ledger-entries: `idempotency_key` is ignored: each repeat of a keyed credit creates a new entry
- `Q4` dodo, POST /refunds (partial): `items[].amount` is read in MAJOR units and silently capped at the line price: every partial refund refunds the whole item
- `Q5` dodo, POST /refunds (full): no duplicate protection (a retried full refund creates a second refund), and full refunds answer slowly
- `Q6` crustdata, POST /company/enrich: notion.so funding.total_investment_usd comes back as the string "$343M"

Scenario `change-api` differs:

- SIMULATED MID-RUN API CHANGE (fixture scenario change-api): right after queue item q09 is decided in each queue run, POST /refunds now reads a partial refund's items[].amount in MINOR units (the documented unit): PLANTED QUIRK Q4 stops for every partial refund from this moment on. In this scenario GET /payments enforces the documented page_size max (PLANTED QUIRK Q1 on GET /refunds only), so refunds can pass the gate.
